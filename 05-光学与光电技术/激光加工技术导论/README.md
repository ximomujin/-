## 公式与推导

对于理想均匀圆形光斑，功率是辐照度在截面面积上的积分，即 $P=I\pi r^2$，所以 $I=P/(\pi r^2)$。若光束是高斯型且 $w$ 表示辐照度降为峰值 $1/e^2$ 的半径，积分得到轴上峰值 $I(0)=2P/(\pi w^2)$。

## 例题

固定功率下，均匀光斑的直径减半，辐照度增加为原来的四倍。比较单位应采用 $\mathrm{W/m^2}$。

## 习题

用相同平均功率比较两个光斑面积下的平均辐照度，标注均匀和高斯光斑定义的区别。

## 应用、实验与验证

用光斑模型和测量数据估计不同功率分布对材料温升的影响。

使用公开数据或仿真分析参数敏感性，实际设备按实验室流程使用。
