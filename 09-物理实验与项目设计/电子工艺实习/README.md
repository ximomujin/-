## 公式与推导

稳态低压直流电阻性负载近似满足 $I=V/R$。若由两个电阻串联，电流相同且两端电压相加，故 $R_{eq}=R_1+R_2$。用实际接线与仪表判据对比静态计算。

## 例题

预先设定的 $5\,\mathrm V$ 教学模型中，串联 $1\,\mathrm{k\Omega}$ 与 $4\,\mathrm{k\Omega}$，理想电流为 $1\,\mathrm{mA}$。

## 习题

对教学低压电路编制通电前测量表，记录导通、极性与电源限流设置。
