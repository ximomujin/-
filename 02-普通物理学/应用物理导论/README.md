## 公式与推导

若小角度单摆周期只依赖长度 $L$ 与加速度 $g$，由量纲 $[T]=[L]^a[g]^b$ 得 $a=1/2,b=-1/2$。无量纲系数需要动力学或测量确定。

## 例题

单摆摆长由 $L$ 增至 $4L$，小角度近似下周期加倍。可先由量纲预测，再测量检验。
