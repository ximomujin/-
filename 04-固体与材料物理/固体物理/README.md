## 公式与推导

一维单原子链的最近邻弹性力为 $K(u_{n+1}+u_{n-1}-2u_n)$。代入 $u_n=Ae^{i(kna-\omega t)}$，得到 $\omega=2\sqrt{K/M}\,|\sin(ka/2)|$，依赖等间距、等原子质量和谐近似。

## 例题

$k$ 很小时 $\omega\approx a\sqrt{K/M}|k|$，从色散曲线的长波斜率可估计声速。

## 习题

对最近邻一维紧束缚色散 $E(k)=\epsilon-2t\cos(ka)$，写出带宽和群速度表达式。

## 应用、实验与验证

用衍射峰定位晶格间距，用能带模型建立半导体输运直觉。
