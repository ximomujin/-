# 线性方程组的扰动与条件数

本页推导及练习由 AI 辅助编写。 [MIT OCW Introduction to Numerical Methods](https://ocw.mit.edu/courses/18-335j-introduction-to-numerical-methods-spring-2019/) · [MathWorks 线性方程组](https://www.mathworks.com/help/matlab/ref/double.mldivide.html)

## 推导

对固定的可逆矩阵 $A$，若 $Ax=b$，右端变化 $\Delta b$ 会导致 $A\Delta x=\Delta b$。由 $\|\Delta x\|\le\|A^{-1}\|\|\Delta b\|$ 和 $\|b\|\le\|A\|\|x\|$ 得

$$
\frac{\|\Delta x\|}{\|x\|}\le\kappa(A)\frac{\|\Delta b\|}{\|b\|},
\qquad \kappa(A)=\|A\|\|A^{-1}\|.
$$

条件数给出最坏方向的放大上界。残差衡量未满足线性方程的程度。实验数据中的右端扰动会改变待解问题本身，即使每个问题的求解残差都很小，得到的参数也可能差异很大。

## 算例

取 $A=\begin{pmatrix}1&1\\1&1.0001\end{pmatrix}$，$b=(2,2.0001)^T$。两行相减得 $0.0001x_2=0.0001$，故 $x=(1,1)^T$。若把第二个读数提高 $10^{-4}$，便得到 $x'=(0,2)^T$。右端相对扰动约 $3.54\times10^{-5}$，解的相对变化为 1。矩阵的二范数条件数约为 $4.00\times10^4$。

~~~matlab
A = [1 1; 1 1.0001];
b = [2; 2.0001];
b_measured = b + [0; 1e-4];
x = A \ b;
x_measured = A \ b_measured;
relative_input = norm(b_measured - b) / norm(b);
relative_output = norm(x_measured - x) / norm(x);
relative_residual = norm(A * x_measured - b_measured) / norm(b_measured);
assert(relative_output <= cond(A) * relative_input)
~~~

在 MATLAB 或 GNU Octave 中运行，基础矩阵运算无需工具箱。核对相对残差接近机器精度，并报告输入和输出相对变化。

## 练习与核验

将第二行第二个系数改为 1.01，右端改为 $(2,2.01)^T$，保持读数扰动 $10^{-4}$。解变为 $(0.99,1.01)^T$，相对变化应为 0.01。
