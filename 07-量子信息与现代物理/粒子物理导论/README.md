## 公式与推导

设质量为 $M$ 的母粒子在静止系中衰变成质量 $m_1,m_2$ 的两粒子，并取 $c=1$。三动量守恒给 $\mathbf p_1=-\mathbf p_2$。将 $p_2^2=(P-p_1)^2=m_2^2$ 展开得 $E_1=(M^2+m_1^2-m_2^2)/(2M)$，还原动量模为 $\sqrt{E_1^2-m_1^2}$。物理阈值要求 $M\ge m_1+m_2$。

## 例题

若两个子粒子均无质量，在静止系各有 $E=M/2$ 和等大反向动量。恢复 SI 单位后每个光子的能量为 $Mc^2/2$。

## 习题

在母粒子静止系写出二体衰变的能动量守恒，检查两子粒子三动量等大反向并推导阈值条件。
