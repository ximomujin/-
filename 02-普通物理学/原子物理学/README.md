# 原子物理学

Atomic Physics · 学习阶段 2

从实验谱线及粒子散射理解原子的结构、量子化与能级间跃迁。

## 前置知识

[力学](../%E5%8A%9B%E5%AD%A6/README.md)、[电磁学](../%E7%94%B5%E7%A3%81%E5%AD%A6/README.md)

## 章节知识树

1. 散射实验和原子模型
2. 光电效应与物质波
3. 氢及类氢原子的能级
4. 角动量、自旋、精细结构
5. 多电子原子、泡利原理及光谱
6. 磁场中的能级和选择定则

## 公式与推导


[专题推导与习题](%E4%B8%93%E9%A2%98%E6%8E%A8%E5%AF%BC%E4%B8%8E%E4%B9%A0%E9%A2%98.md)提供逐步推导、计算例题和解答。

光子能量 $h\nu=hc/\lambda$。忽略氢原子的精细结构等修正，$E_n=-13.6\,\mathrm{eV}/n^2$，从 $n_i$ 向更低 $n_f$ 的跃迁发射能量 $E_{n_i}-E_{n_f}$。

## 例题

氢的 $n=3\to2$ 能量差约 $1.89\,\mathrm{eV}$，用 $hc\approx1240\,\mathrm{eV\,nm}$ 得发射波长约 $656\,\mathrm{nm}$。

## 习题

计算氢的巴耳末系极限波长，并解释相邻谱线为何在极限附近变得密集。

## 应用、实验与验证

利用元素特征发射谱识别气体成分。

对教学光谱的波长标定曲线做线性或分段拟合，检查残差。
