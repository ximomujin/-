## 公式与推导

独立同分布且方差有限时，利用方差对独立和的可加性得到 $\operatorname{Var}(\bar X)=\sigma^2/n$。均值标准误差为 $\sigma/\sqrt n$，增加重复测量次数可降低独立随机误差。

## 例题

独立重复测量 25 次，单次标准差估计为 $0.10\,\mathrm{s}$，均值标准误差约 $0.020\,\mathrm{s}$。

## 习题

比较样本量 $n=20$ 与 $n=80$ 时均值的方差，再讨论测量共享同一零点漂移时为什么会偏离 $1/n$。
