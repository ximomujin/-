# 光学

Optics · 学习阶段 2

根据尺度选择光线、标量波或矢量描述，理解成像、干涉、衍射和偏振。

## 前置知识

[力学](../%E5%8A%9B%E5%AD%A6/README.md)

## 章节知识树

1. 传播、折射、全反射与几何成像
2. 光波、相位与相干性
3. 双束、多束干涉及典型应用
4. 夫琅禾费衍射和光栅
5. 偏振、二向色性与波片
6. 成像分辨率和仪器

## 公式与推导

双缝中心距为 $d$ 时，远场的光程差为 $d\sin\theta$。同相照明下亮纹满足 $d\sin\theta=m\lambda$，近轴时屏上间距近似 $\lambda L/d$。

## 例题

取 $\lambda=600\,\mathrm{nm}$、$L=1\,\mathrm m$、$d=0.30\,\mathrm{mm}$，近轴条纹间距约 $2.0\,\mathrm{mm}$。

## 习题

推导单缝远场一级暗纹角位置，比较改变波长与缝宽分别对主瓣宽度的影响。

## 应用、实验与验证

用衍射极限估计显微成像分辨率，以干涉条纹测微小位移。

在合规教学装置上测条纹间距；对可调参数做误差传播。
