建立质点、系统和刚体模型，理解运动方程与守恒律何时适用。

## 公式与推导


[专题推导与习题](%E4%B8%93%E9%A2%98%E6%8E%A8%E5%AF%BC%E4%B8%8E%E4%B9%A0%E9%A2%98.md)提供逐步推导、计算例题和解答。

质点质量不变且处于惯性系时，将 $m\dot{\mathbf v}=\mathbf F$ 与 $\mathbf v$ 点乘得到 $d(mv^2/2)/dt=\mathbf F\cdot\mathbf v$。沿轨迹积分即得动能定理。

## 例题
