# 高等数学

Calculus · 学习阶段 1

用局部变化率描述运动和场，用积分把局部量汇总为整体量。先在一维熟练使用极限，再推广到多元函数。

## 前置知识

先预习本页概念和术语。

## 章节知识树

1. 函数、极限与连续
2. 导数、微分与泰勒展开
3. 定积分与微积分基本定理
4. 常微分方程初步
5. 数项级数、幂级数与收敛域
6. 多元微分、梯度与极值
7. 重积分、坐标变换与向量积分

## 公式与推导

若 $f$ 在区间连续，定义 $F(x)=\int_a^x f(t)\,dt$。差商 $(F(x+h)-F(x))/h$ 是短区间上 $f$ 的平均值，连续性给出 $F'(x)=f(x)$。因此变速运动中对速度积分可得位移。

## 例题

已知 $v(t)=v_0+at$，位移为 $\int_0^T v(t)\,dt=v_0T+aT^2/2$。量纲为长度。

## 习题

用极坐标计算 $\iint_{x^2+y^2\le 1}(x^2+y^2)\,dx\,dy$，检查雅可比因子。参考值 $\pi/2$。

## 应用、实验与验证

将速度传感器数据积分成位移，比较累积偏置对估计的影响。

用矩形法和梯形法积分同一数据，对比步长减半时的误差。
