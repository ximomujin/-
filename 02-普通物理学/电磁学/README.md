# 电磁学

Electricity and Magnetism · 学习阶段 1

用场描述电荷和电流的相互作用，沿着静电、稳恒磁场和感应现象理解电磁规律。

## 前置知识

[力学](../%E5%8A%9B%E5%AD%A6/README.md)

## 章节知识树

1. 电场、通量与高斯定律
2. 电势、电容及电介质
3. 直流电路、功率和稳恒电流
4. 毕奥–萨伐尔定律与安培定律
5. 法拉第定律、耦合和电磁波初步

## 公式与推导


[专题推导与习题](%E4%B8%93%E9%A2%98%E6%8E%A8%E5%AF%BC%E4%B8%8E%E4%B9%A0%E9%A2%98.md)提供逐步推导、计算例题和解答。

有球对称性且半径 $r$ 的高斯面包围电荷 $Q$ 时，通量为 $4\pi r^2E$。由高斯定律得 $E=Q/(4\pi\epsilon_0r^2)$，方向取径向。

## 例题

理想无限长直导线以半径 $r$ 的圆为安培回路，可得 $B=\mu_0I/(2\pi r)$。导线有限时边缘区域需修正。

## 习题

求均匀带正电绝缘球在球内和球外的径向电场，检查表面连续性和原点极限。

## 应用、实验与验证

用场和电势模型说明电容式测距、静电屏蔽和感应线圈。

在低压电路中测 RC 充电曲线，检查拟合时间常数与元件标称值。
