# 知识库管理工具

在仓库根目录运行。需要 Python 3.10 或更新版本。仓库容量依赖 Git，PDF 逐页解码依赖 Poppler 的 `pdftoppm`。链接检查需要网络。

| 命令 | 结果 |
| --- | --- |
| `python "16-知识库管理工具/维护.py" 生成索引` | 根据主题数据库重建主题总索引、阶段索引和学科索引。 |
| `python "16-知识库管理工具/维护.py" 生成清单` | 生成教材资源核验索引并检查本地存档。 |
| `python "16-知识库管理工具/维护.py" 核验资源` | 比对文件大小和 SHA-256，检查是否记录许可证、来源及授权证据链接。 |
| `python "16-知识库管理工具/维护.py" 文件去重` | 列出 SHA-256 完全相同的文件。 |
| `python "16-知识库管理工具/维护.py" 检查PDF` | 检查 PDF 文件边界，并尝试逐页解码。可加一个或多个仓库内相对路径。 |
| `python "16-知识库管理工具/维护.py" 检查链接 --写入` | 检查清单中的公开链接，将结果写入 `维护记录/链接核验.json`。 |
| `python "16-知识库管理工具/维护.py" 统计进度 --写入` | 汇总进度百分比和已完成主题数，重建根目录的 `学习进度.md`。 |
| `python "16-知识库管理工具/维护.py" 检查容量` | 报告工作树及 Git 数据的字节数、最大文件和 1 GiB 软预算。 |

主题索引以 `00-学习导航/主题数据库.json` 的 `courses` 数组为准，进度从同目录的 `学习进度.json` 读取。使用 `topic_id` 关联主题 `id`。进度为 0 至 100，空白主题按 0% 汇总。

教材清单是 `12-教材与学习资源库/资源清单.json`。已人工核实再分发许可，且已填写 `license`、`license_evidence_url`、`official_url` 和 `download_url` 后，可在资源记录中登记已下载文件的大小、校验值与日期。

```bash
python "16-知识库管理工具/维护.py" 更新存档校验 <资源编号> "12-教材与学习资源库/实际文件路径.pdf"
python "16-知识库管理工具/维护.py" 生成清单
```

如果下载失败，使用资源编号、公开链接和具体原因登记。重试结果可通过 `--重试结果` 记入 `12-教材与学习资源库/下载失败记录.json`。

```bash
python "16-知识库管理工具/维护.py" 记录下载失败 <资源编号> "<公开下载链接>" "<失败原因>"
```

清单和失败记录采用原子替换。工具提示记录正在更新时，等上一次更新结束后重试。如果更新进程已被强制终止，可清理对应的空 `.文件名.lock` 目录后重试。

发现重复文件时，先更新引用、确认 Git 工作区内容，再指定要删除和保留的文件。工具会比对内容并检查 Markdown、JSON、CSV 等文件中的可能引用。

```bash
python "16-知识库管理工具/维护.py" 文件去重 --删除 "<重复文件相对路径>" --保留 "<保留文件相对路径>"
```

链接检查只发送公开 HTTP 请求。HTTP 404 或 410 记为失效，访问受限、超时、连接错误等记为待核实。可通过 `--超时`、`--并发` 调整或指定待查 JSON 文件。校验程序退出码 `1` 表示已发现问题或超预算，`2` 表示输入有误或缺少 PDF 逐页检查依赖。PDF 可解码与 SHA-256 匹配用于检验文件完整性。再分发许可由维护者阅读官方条款确认。
