## 公式与推导

按系统对外做功为正，第一定律 $dU=\delta Q-p\,dV$ 适用于准静态仅做体积功的过程。理想气体等温时 $dU=0$，故 $Q=W=nRT\ln(V_2/V_1)$。

## 例题

$1\,\mathrm{mol}$ 理想气体在 $300\,\mathrm K$ 可逆等温膨胀至两倍体积，对外做功约 $1.73\,\mathrm{kJ}$。

## 习题

画出同初态、膨胀到同体积的可逆绝热与可逆等温 $p$-$V$ 路径，解释哪条曲线的做功较大。

## 应用、实验与验证

评估保温和换热过程中的功率、温差与理想效率上限。

记录冷却曲线，用半对数图检查牛顿冷却模型适用的时间区间。
