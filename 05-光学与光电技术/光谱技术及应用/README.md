## 公式与推导

正入射平面光栅的相邻缝距为 $d$，主极大满足 $d\sin\theta=m\lambda$。在固定级次求导得角色散 $d\theta/d\lambda=m/(d\cos\theta)$。

## 例题

光栅为 $600$ 条每毫米，$\lambda=500\,\mathrm{nm}$ 正入射，一级衍射角约 $17.5^\circ$。

## 习题

根据同一标准的多个已知波长，比较一次标定与二次标定的残差并讨论如何判别过拟合。

## 应用、实验与验证

以谱线数据识别元素，评估仪器分辨率对谱峰重叠的影响。

用标准发射谱校准波长轴，记录拟合不确定度、重复性和峰宽。
