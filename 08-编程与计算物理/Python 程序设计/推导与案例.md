## 推导

实验数据常由采样时刻 $t_i$ 和读数 $f_i$ 构成。相邻样本间用直线插值，积分为该段梯形的面积。非等间隔情况下，

$$
Q\approx \sum_{i=0}^{N-2}(t_{i+1}-t_i)\frac{f_i+f_{i+1}}{2}.
$$

如果 $f$ 是流量（$\mathrm{m^3/s}$），$Q$ 是体积（$\mathrm{m^3}$）。若读数表示有限时间窗的平均值，先核对时间戳标记的是窗的起点、中心或终点。

## 合成算例

时刻为 $[0,1,3]$ s，读数为 $[0,2,6]\,\mathrm{m^3/s}$。两段面积分别为 $1$ 和 $8\,\mathrm{m^3}$，总量为 $9\,\mathrm{m^3}$。信号恰为 $f(t)=2t$，梯形法在该节点上给出精确积分。

~~~python
from math import isfinite


def integrate_samples(time, amplitude):
    if len(time) != len(amplitude) or len(time) < 2:
        raise ValueError("需要至少两对样本")
    if not all(isfinite(value) for values in (time, amplitude) for value in values):
        raise ValueError("样本必须为有限数")
    intervals = [right - left for left, right in zip(time, time[1:])]
    if any(interval <= 0 for interval in intervals):
        raise ValueError("时间必须严格递增")
    return sum(
        interval * (left + right) / 2
        for interval, left, right in zip(intervals, amplitude, amplitude[1:])
    )


assert integrate_samples([0, 1, 3], [0, 2, 6]) == 9.0
~~~

将代码保存到临时文件后用 Python 3 运行，无需额外依赖。预期断言通过。切片与 zip 保持每个读数和时间间隔的对应关系。

## 练习与核验

1. 将读数乘以 −1，得到 −9。物理解释取决于仪器规定的正向。
2. 用 $f(t)=t^2$、$t\in[0,2]$ 核验积分。取 2 个与 4 个等距区间，梯形值分别为 3 和 2.75，解析值为 $8/3$。
3. 传入重复时刻、NaN 或不等长的数组。分别确认错误原因可从异常消息识别。
