## 公式与推导

识别数组形状与所需统计轴。对于一组等权测量，样本均值 $\bar x=(1/N)\sum_i x_i$。如果移动平均窗口宽度为 $w$，相邻窗口的和可以通过减掉移出值并加上新值更新。

## 例题

序列 [2, 4, 6, 8] 的宽度 2 移动均值为 [3, 5, 7]。确认输出长度为 3，并记录空输入策略。

## 习题

用两种写法计算同一离散正弦序列的均值，设定误差阈值并检查数组维度。

## 应用、实验与验证

批量整理实验测量、绘图和保存可重跑的计算。

用不等间隔读数积分总量，检查采样时间与读数切片的一一对应。运行记录应含输入、单位、边界策略及预期结果。
