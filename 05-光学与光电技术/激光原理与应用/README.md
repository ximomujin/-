## 公式与推导

令 $g$、$\alpha_i$ 分别是单位长度的强度增益与内损耗。长度 $L$ 的线形腔往返一周强度乘以 $R_1R_2e^{2(g-\alpha_i)L}$。阈值取倍增因子为 1，得 $g_\mathrm{th}=\alpha_i+\ln[1/(R_1R_2)]/(2L)$。

## 例题

令 $L=0.30\,\mathrm m$、$R_1=0.99$、$R_2=0.90$，镜面损耗换算的阈值项约为 $0.192\,\mathrm{m^{-1}}$。
