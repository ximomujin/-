## 公式与推导

相邻等距晶面的散射光路程差为 $2d\sin\theta$。相长干涉要求路程差是整数倍波长，故 $2d\sin\theta=n\lambda$。实验读数若为 $2\theta$，代入前先折算。

## 例题

一级峰位 $2\theta=30^\circ$、波长 $0.154\,\mathrm{nm}$，得到 $d=0.154/[2\sin15^\circ]\,\mathrm{nm}\approx0.298\,\mathrm{nm}$。

## 习题
