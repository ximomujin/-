## 公式与推导

若 $y=f(x_1,\ldots,x_n)$ 且输入互不相关，在工作点一阶展开后有 $u_c^2(y)\approx\sum_i (\partial f/\partial x_i)^2u^2(x_i)$。相关量须增加协方差项，强非线性时要检验线性化是否充分。

## 例题

独立测得 $L=10.0\,\mathrm{cm}$、$W=5.0\,\mathrm{cm}$ 且标准不确定度均为 $0.1\,\mathrm{cm}$，则面积为 $50.0\,\mathrm{cm^2}$，合成标准不确定度约 $1.1\,\mathrm{cm^2}$。

## 习题

独立测量长度 L 和宽度 W 时推导面积 A = L W 的一阶合成标准不确定度，写明独立性假设。
