## 公式与推导

广度优先搜索把起点放入队列并令其距离为 0。每次出队时，未访问邻点被赋予当前距离加 1 后入队。归纳可知队列中顶点按距离层次被发现，所以得到无权图中边数最少的路径。邻接表实现对每个顶点与每条边最多作常数次处理，复杂度 $O(V+E)$。

## 例题

从 A 出发，在边 A–B、A–C、B–D、C–D 的图中，D 最短距离为 2，可有多个前驱选择。

## 习题

在小型图上手算 BFS 距离，再用相同测试输入校验代码，对照入队与出队次序。
